# 工资发放账户弹框

基于2102711，只修改工资页的发放弹框及其四个处理函数。后端没有改动，撤销发放函数和弹框、其他按钮绑定及业务函数AST与基线一致。未部署。

## 实现

- 单张显示实发合计、1人、账户选择及原有可选签字照片。
- 批量显示选中单数、本次可发单数、实发合计及去重人数；只提交已确认、未作废、未发放的选中单，固定弹框打开时的集合。
- GET `/accounts`取当前仓库的启用泰铢账户，现金、银行都能选；优先现金，没有现金选第一个。与上轮后端币种限制一致。
- 清空账户后点击确认，提示“请选择工资发放账户”，不会请求发放接口。账户加载中、加载失败、无可用账户时禁用提交。
- 无可用账户提示：“还没有可用的泰铢收款账户，请先到收款账户里建一个或启用账户”。
- 单笔请求保留签字照片，加account_id；批量同一account_id随record_ids提交。成功提示追加“已记入运营支出”。失败保留弹框和所选账户，不显示成功提示。
- 工资单明细原来的直接发放入口也改为先打开同一账户弹框，避免漏传账户；按钮本身和撤销入口没改。
- 手机弹框最大85dvh，正文独立滚动，标题及底部按钮不缩；层级高于页面回顶部按钮。
