字段及行为
audit_logs.ip_country VARCHAR(100)、ip_region VARCHAR(150)、ip_city VARCHAR(150)，都可空。
启动迁移 ADD COLUMN IF NOT EXISTS，每列独立保存点；失败报告并中止，避免半迁移启动。
不UPDATE、不回填历史日志；老记录三列NULL，前端地区空白。
新记录查不到用三个空字符串，前端显示「未知」；内网为country=内网，其余为空。
统一 get_ip_location，登录及其他成功写操作均由原审计中间件调用。
不改上一轮 get_client_ip、防伪、登录身份、权限校验、请求及响应内容。
没有密码、令牌、表单内容、坐标写入日志。
内网按实际私有段：10/8、172.16/12、192.168/16，以及回环、链路本地、IPv6 ULA。
172不是整个网段都私有，例如172.217公网仍查库，避免误标。
0.0.0.0、无效值、文档保留地址、查不到、库缺失/损坏均返回空，不影响登录和业务。
库中中文名称优先；曼谷/中国部分省市用展示翻译，未翻译的原英文保留，不编造位置。
免费版精度有限，地区代表IP库归属，不证明本人实际地理位置。
