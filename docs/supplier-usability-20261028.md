3. **普通规格表单**：目录新建/编辑、人工映射、导入预览映射、供应商新产品共用递归表单；文字、数字、是否、尺寸/单位、嵌套分组及历史多项规格可以无损往返。后端仍收到原来的 attributes/confirmed_attributes，不把前端草稿结构写入业务记录。不会要求用户手写原始 JSON；Excel 旧结构化列保持兼容且可留空后人工核实。
4. **既有入口完整流程**：实际验证 SKU 新建、编辑回显、人工映射、模板下载、仅示例模板阻止确认、实际合成文件预览与勾选确认后导入。保留导入原文件/原请求重试、版本校验与人工依据要求，没有自动合并/覆盖旧报价。

6. **对账**：只补创建账单已生成的差异说明落库，账单金额、付款和审核计算未改。
7. **AI 成功结果保存保护**：只用已有字段和已有历史表补时间与依据；保留 HTTP 权限，不增加自动业务决策。
