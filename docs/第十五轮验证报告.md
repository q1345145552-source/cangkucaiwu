# 第十五轮：主管员工自助

测试使用本机临时 SQLite 数据库、隔离后端与前端正式构建，没有连接线上业务库，没有部署。

## 菜单

纳入考勤的主管在原管理菜单之后，增加“员工自助”分组：

| 入口 | 地址 | 页面 |
| --- | --- | --- |
| 打卡签到 | /clock-in | 原劳工打卡页 |
| 工作考勤 | /my-attendance | 原考勤页的本人视图 |
| 加班管理 | /my-overtime | 原加班页的员工视图 |
| 我的工资单 | /my-payslip | 原劳工工资单页 |
| 请假 | /my-leave | 原考勤页直接打开本人请假表单 |

主管关闭开关并重新登录：员工分组消失，管理菜单保留。财务、管理员、超管没有新增员工入口；劳工原四个入口保留，请假仍从原考勤页提交。管理菜单的地址、图标、顺序和功能权限筛选没有改动。员工自助不新增可勾选的功能权限。

## 接口范围

只有下列路由支持新增主管员工身份。共享读取须明确带 `view=self`，未带参数仍走原管理权限。

| 模块 | 路由 |
| --- | --- |
| 打卡 | POST /clock-in；GET /clock-in/today |
| 本人考勤配套读取 | GET /clock-in/records；GET /clock-in/photos；GET /attendance/calendar；GET /attendance/leaves；GET /attendance/rest-days |
| 本人请假 | POST /attendance/leaves?view=self |
| 员工加班 | POST /overtime/{id}/confirm；POST /overtime/{id}/dispute；GET /overtime/pending |
| 员工加班配套读取 | GET /overtime?view=self；GET /overtime/monthly-hours?view=self；GET /overtime/limit?view=self |
| 本人工资单 | GET /payroll/my-payslip |
| 工资单配套读取 | GET /employee-advances/my-debt |

配套接口一并处理，避免页面能打开却取不到自己的照片、休息日、待确认任务或欠款。没有开放管理写接口。创建加班任务时，正式绑定的已纳入考勤主管可被识别为该档案的登录账号，不通过同名猜测绑定。
