二、接口和迁移
现有代码没有单独的开销编辑/删除接口，本轮补齐：
PUT /api/v1/expense-fund/accounts/{account_id}/items/{item_id}
DELETE /api/v1/expense-fund/accounts/{account_id}/items/{item_id}，请求体 {"reason":"原因"}
POST /api/v1/expense-fund/accounts/{account_id}/items/{item_id}/upload-receipt 保留地址并收紧权限、增加日志。
三处均只允许仓库管理员，保留仓库归属校验。作废和编辑不触发支付或工资重算。
新增三个可空列：voided_by、voided_at、void_reason。
启动迁移使用 ADD COLUMN IF NOT EXISTS，每列独立保存点，不回填旧数据。
作废仅修改该行状态和留痕字段，不物理删除，不直接增减备用金余额字段。
台账、可用余额、充值申请、拨付来源和历史流水读取只增加排除作废记录的条件，保留原计算公式。
报销/预支关联的系统开销必须从原业务模块处理，不能从手工开销入口更改或作废。
