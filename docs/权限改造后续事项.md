# 权限改造后续事项

以下规则由用户在第十二轮前明确决定，不再作为待确认问题：

- 配置中心：有“配置中心”权限的主管、财务都能读；写操作只给管理员和主管，财务不能改作息、红线。具体放开另行实施，第十二轮不改配置接口。
- 修改日志：按“修改日志”功能权限控制，勾了可看、未勾不可看。清单已有同名可勾项；旧接口的管理员角色限制需在后续对应轮次放开。
- 员工人数上限接口的既有 422 路由问题：排在这批改造后，单独一轮修复。

第十二轮只建立账号身份字段：

- `users.attendance_enabled`：默认 false，仅主管、财务的身份开关生效。
- `users.attendance_employee_id`：可空，关联员工档案；由服务端维护。
- `users.attendance_enabled_at`：可空，记录本次开启时间；关闭时清空。
- 第十二轮仅添加字段；第十三轮已实现打开时自动建档/复用并绑定，关闭只解除关联，不删除员工档案或业务记录。
- 权限清单中的 `attendance_enabled` / “纳入考勤”不可勾选、没有页面地址，不进入功能权限列表或菜单。

后续主管员工化须同步检查：打卡、我的考勤、加班确认/异议、我的工资单原先的劳工角色限制。本轮未改这些业务接口。

第十三轮绑定规则：

- 新档案姓名取账号显示名、工号沿用账号用户名、岗位为仓库主管、状态正式、仓库取账号所属仓库、入职日期取泰国当天。
- 薪资模板和扣款模板先留空，接口返回到员工档案设置模板的提示。
- 优先复用账号关联或已绑定该账号的档案；关闭后的原档案从该账号开关日志恢复关联，不按姓名猜测。
- 已绑定其他账号、跨仓库或已删除的档案不自动接管或恢复；返回中文提示。
- 建档/绑定、开关和修改日志在同一事务中完成；不改变账号角色，不修改工资、考勤计算或前端。

第十五轮已完成主管员工自助：

- 仅 `supervisor && attendance_enabled` 增加员工自助身份；劳工保持原入口，财务、管理员、超管不新增员工入口。
- 原管理菜单、功能勾选和管理接口保持原规则；员工自助另外显示打卡、个人考勤、员工加班、我的工资单、请假。
- 共享考勤/加班读取使用 `view=self`；只查询明确绑定的本人档案及其仓库。没有 `view=self` 的管理请求仍需原功能权限。
- 个人视图复用劳工页面，缅甸语／泰语单独保存，不切换账号角色，不改工资与考勤计算。
- 登录和 `/auth/me` 返回考勤开关、关联档案编号；关闭后服务端立即拒绝本人入口，不依赖重新签发令牌。

第十六轮已完成主管工资与人效：

- 正式绑定主管沿用统一工资流程；列表及明细显示主管标签，已有工资单不自动重算。
- 人效纳入开启考勤且双向同仓绑定的主管；关闭后排除其正常、补录及加班工时。劳工原有公式与口径保留，财务、管理员、超管不纳入。
- 标签与统计范围通过独立身份解析服务复用；不把岗位名称当作账号角色。

第十七轮已完成预支审批状态基础：

- `employee_advances` 新增 approval_status / reviewer_id / reviewed_at / reject_reason；启动脚本逐列保存点加列，旧记录默认已通过，NULL 幂等回填，不覆盖待审批或已驳回。
- 管理员创建直接已通过；主管给自己记（包括关闭考勤后保留的本人档案）待审批，给别人记直接已通过。原权限与仓库校验保留。
- 列表支持审批状态筛选，本人欠款接口额外返回带审批字段的本人记录，旧汇总字段保留。
- 下一轮继续审批/驳回及工资过滤。本轮未改工资、汇总和备用金联动，不单独部署为完整审批闭环。

小时请假口径已按用户新规则修正：

- 考勤与工资共用小时假净工时服务，额外扣除 max(请假合计小时−配置下班点对应早退时长, 0)，净工时不为负并保留两位。
- 小时假按净工时/应有工时折算出勤；月薪该路径按净出勤比例计入，避免再次扣同一段小时假。
- 精确示例四次卡08:41:54/12:02:00/12:48:04/15:25:47，小时假2.3，净工时从3.66变为5.96。老工资单不自动变，需人工重算。
- 全天假带打卡仍保留工时是既有其他路径，本轮按限制没有改；与“全天假工时零”的预期差异已记录在专项报告。

早退请假豁免已按用户新规则完成：

- 当天已通过的全天假豁免早退；下午假覆盖下午早退，上午假不覆盖下午早退。
- 小时假合计加0.5小时容差，大于等于配置下班点对应早退时长则豁免，否则仍按原模板罚。
- 精确案例手动重算：工时仍5.96，测试早退扣款50→0；迟到、净工时服务、请假数据和老单读取行为不变。

半天假折算已完成：

- 上午、下午半天假按配置中心对应时段换算为小时，考勤和工资共用服务；已缺少的打卡时段不重复扣。
- 半天假出勤改为净工时/当天应有工时，日薪、月薪同步按实际出勤支付；小时假和早退豁免不变。
- 测试配置3/5小时，对应日薪400元应发250/150元；上午改为2小时后按7小时全天分母折算，验证后恢复。
- 请假数据、历史工资单不自动变更，未部署；见《半天假按配置时段折算验证报告》。
