## 1. 系统概述

本系统为海外仓财务管理一体化平台，覆盖客户管理、资金对账、收支统计、供应商采购、备用金报销、账期信用、拼单采购等核心业务场景。支持多仓库独立核算，三种角色权限隔离。

**访问地址**：`https://xtfinance.site`

---

## 2. 角色与权限

| 角色 | 标识 | 权限范围 |
|------|------|---------|
| 超级管理员 | super_admin | 全系统管理，可操作所有仓库数据，系统设置 |
| 仓库管理员 | warehouse_admin | 管理本仓库全部财务数据 |
| 员工 | staff | 受限访问，仅可见被授权的功能模块 |

仓库管理员可在系统设置中为员工分配额外权限（如到账流水录入、备用金管理等）。

---

## 3. 仪表盘

登录后的首页，展示本仓库的核心运营数据概览：

- 充值总额与到账总额对比
- 未匹配申报数量提醒
- 近期收支趋势
- 备用金余额告警

点击任意数据卡片可跳转至对应功能页面。

## 4. 财务（仓库运营）

### 4.1 客户档案

管理所有客户的完整信息档案。

**操作说明**：

| 操作 | 步骤 |
|------|------|
| 新建客户 | 点击"新建客户" → 填写客户编号、公司名称、联系人、联系方式、微信账号、常用货品类型、常用物流渠道 → 勾选"账期客户"可设置信用额度和还款日 → 保存 |
| 编辑客户 | 点击客户行操作列的编辑按钮 → 修改信息 → 保存 |
| 删除客户 | 点击客户行操作列的删除按钮 → 确认后删除 |
| 筛选客户 | 顶部筛选栏支持按账期客户（是/否）筛选、按公司名称或编号搜索 |

**字段说明**：

| 字段 | 说明 |
|------|------|
| 客户编号 | 系统唯一标识 |
| 公司名称 | 必填 |
| 微信账号 | 对方的微信号 |
| 常用货品类型 | 普货 / 敏感货 / 品牌货 |
| 累计发货单数 | 系统自动统计 |
| 累计发货运费 | 系统自动统计 |
| 欠款金额 | 系统根据账期自动计算 |

---

### 4.2 仓库管理

仅超级管理员可见。管理系统中的所有仓库，可新建、编辑、删除仓库。

---

### 4.3 收款账户

管理公司各收款账户。

**字段说明**：

| 字段 | 说明 |
|------|------|
| 账户名称 | 便于识别的账户名 |
| 账户类型 | 银行账户 / 支付宝 / 微信 |
| 开户银行 | 仅银行账户时填写 |
| 开户支行 | 支行名称 |
| 账户持有人 | 姓名 |
| 币种 | 泰铢 / 人民币 |
| 月初余额 | 每月初的账户余额 |
| 状态 | 启用 / 停用 |

停用的账户不会出现在充值申报等页面的下拉选项中。

---

### 4.4 充值申报

客户充值行为的申报入口。系统采用行内录入模式，无需弹窗。

**操作流程**：

1. 在页面顶部的录入行中选择客户，系统自动填入该客户的默认币种和付款方式
2. 输入金额，上传付款截图
3. 点击"提交申报"
4. 申报记录出现在下方列表，状态为"待匹配"

**截图说明**：截图非必填，但只有上传了截图的申报才能进入对账中心参与匹配。未上传截图的申报在列表中显示"未上传"红色标记，可点击"补传"按钮后补。

---

### 4.5 到账流水

银行到账记录的录入入口。同样为行内录入模式。

**操作流程**：

1. 选择到账日期（默认当天），输入金额
2. 选择付款方（关联已有客户，便于后续对账）
3. 选择币种和付款方式
4. 可选上传截图
5. 点击"录入"

**批量导入**：点击"下载模板"获取 Excel 模板，填写数据后点击"批量导入 Excel"上传。

---

### 4.6 对账中心

手动匹配充值申报与到账流水，确保每笔充值都有对应的银行到账记录。

**操作流程**：

1. 页面打开后自动加载当月数据
2. 左侧为"未匹配的充值申报"，右侧为"未匹配的到账流水"
3. 在左侧点选一条申报，右侧点选一条流水，中间出现"匹配"按钮
4. 点击匹配，填写备注（可选），点击确认
5. 匹配成功后两条记录从待匹配列表消失，出现在下方"已匹配记录"区域

**解除匹配**：在已匹配记录列表中点击"解除匹配"，两条记录恢复为未匹配状态。

**导出**：支持按时间范围、客户名称、客户编号筛选后导出已匹配记录的 Excel。

## 5. 财务（日常开支）

### 5.1 运营收支

展示仓库运营相关的收入与支出全貌。

**页面结构**：

| 区域 | 内容 |
|------|------|
| 收入趋势图 | 近 12 个月的充值收入折线图，当前月份高亮 |
| 支出管理 | 运营支出列表，支持按月份/类别/币种/账户筛选 |
| 收支对比 | 按月或按周切换，展示收入 vs 支出 vs 盈亏 |

**录入支出**：点击"录入支出" → 选择类别（仅显示运营类类别，如工资、电费、耗材、房租等） → 填写金额、币种、日期 → 保存。

**运营类类别默认包含**：工资、电费、耗材、房租、保护费、办公用品费、设备费。

---

### 5.2 其他收入

记录非运营类的其他收入（如纸壳销售、二手设备出售等）。

**页面结构**：

- 顶部显示当月其他收入合计
- 列表显示日期、分类、物品说明、金额、币种、备注
- 支持按月份和币种筛选
- 每条记录可编辑和删除

**录入其他收入**：点击"新建" → 选择分类 → 填写物品说明（卖了什么东西） → 输入金额、选择币种 → 保存。

**币种展示切换**：列表顶部可切换"显示为泰铢"或"显示为人民币"，系统自动按汇率换算展示，不影响原始存储金额。

---

### 5.3 备用金管理

采用活账户模式，每位员工拥有一个备用金账户，上限默认 5,000 铢。

**核心概念**：

| 概念 | 说明 |
|------|------|
| 账户余额 | 当前可用余额 |
| 总额（累计领用） | 该员工历史上累计领用的备用金总额 |
| 上限 | 管理员在系统设置中设定，默认 5,000 |
| 警戒线 | 余额低于此值时红色高亮提醒，默认 500 |

**操作流程**：

| 操作 | 步骤 |
|------|------|
| 创建账户 | 仓库管理员点击"新建" → 选择员工 → 保存 |
| 补充备用金（刷新） | 点击员工的"刷新"按钮 → 输入补充金额 → 提交（余额增加但不能超过上限） |
| 录入开销 | 进入员工账户 → 填写开销日期、类别、金额、币种 → 可选上传凭证截图 → 提交 |
| 审核开销 | 切换到"审核"标签 → 查看待审核记录 → 逐条或批量通过/驳回 → 驳回时需填写原因 |

**关联报销**：在报销管理中勾选"关联备用金扣款"后，报销金额自动从备用金余额扣除，并转入备用金审核队列。

---

### 5.4 报销管理

员工提交费用报销，管理员审批出款。

**操作流程**：

| 步骤 | 说明 |
|------|------|
| 提交报销 | 页面顶部行内录入：选择日期、类别、金额、币种 → 填写说明 → 可选上传截图 → 提交 |
| 正常流程 | 提交后状态为"待审批" → 管理员审批通过 → 出款标记"已付款" |
| 关联备用金 | 勾选"关联备用金扣款" → 提交后自动扣减备用金余额 → 报销单只读 → 转入备用金审核 |

**报销类别**（数据库存储，按仓库隔离）：交通费、餐饮费、办公用品、通讯费、差旅费、水电费、维修费、其他。

**审批**：切换到"审批"标签 → 查看待审批记录 → 逐条通过/驳回或批量操作。

**状态说明**：

| 状态 | 说明 |
|------|------|
| 待审批 | 已提交，等待管理员审批 |
| 已通过 | 审批通过，等待出款 |
| 部分通过 | 部分条目通过 |
| 已驳回 | 审批不通过，可查看驳回原因 |
| 已付款 | 已出款完成 |
| 转入备用金审核 | 关联备用金的报销单，已转入备用金审核流程 |

---

### 5.5 账期管理

管理客户的信用账期，支持发货记录、还款记录、评级评估。

**核心概念**：

| 概念 | 说明 |
|------|------|
| 信用额度 | 该客户可欠款的上限金额 |
| 当前欠款 | 系统根据发货总额 - 还款总额实时计算 |
| 逾期天数 | 自最后一次还款或发货日期起算的天数，欠款 ≤ 0 时归零 |
| 还款日 | 每月固定还款日期（1-31） |

**操作流程**：

| 操作 | 步骤 |
|------|------|
| 创建账期 | 选择客户 → 设置信用额度、还款日 → 保存 |
| 录入发货 | 进入客户详情 → 填写发货日期、订单号、金额 → 保存 |
| 录入还款 | 进入客户详情 → 填写还款日期、金额 → 保存 |
| 查看评估 | 系统自动计算评级（A/B/C）、准时率、逾期次数、月均还款额等 |

**客户评级标准**：

| 评级 | 条件 |
|------|------|
| A 级（绿色） | 近 3 个月无逾期，还款准时，合作超半年 |
| B 级（蓝色） | 有 1-2 次逾期但每次及时还清 |
| C 级（红色） | 多次逾期或单次超 30 天或合作不足 3 个月 |

**看板功能**：显示总欠款、总客户数、逾期客户数、评级分布、额度使用率等。

---

### 5.6 报表中心

8 张独立报表，每张卡片右上角实时显示当月数据预览。

**可用报表**：

| 报表 | 核心数据 |
|------|---------|
| 充值汇总 | 当月总充值金额、总笔数 |
| 到账汇总 | 当月总到账金额、总笔数 |
| 收支报表 | 总收入（含充值 + 其他收入）、总支出、净额 |
| 应付报表 | 待付总额、逾期笔数 |
| 备用金报表 | 在途总额、笔数 |
| 报销报表 | 当月报销总额、笔数 |
| 账期报表 | 总欠款、逾期客户数 |
| 对账差异 | 差异笔数、总差额 |

**操作**：点击报表卡片加载数据 → 选择月份切换时间范围 → 点击"导出 Excel"下载当前数据。

---

### 5.7 资金流水总览

全系统资金变动的统一汇总视图，聚合 7 个模块的数据。

**数据来源**：

| 来源模块 | 类型 | 说明 |
|---------|------|------|
| 充值申报 | 收入 | 每笔客户充值 |
| 到账流水 | 收入 | 每笔银行到账 |
| 备用金领用 | 支出 | 每次补充备用金 |
| 备用金开销 | 支出 | 每笔开销记录 |
| 报销 | 支出 | 已付款的报销出款 |
| 应付账款 | 支出 | 每笔应付付款 |
| 手工收支 | 收入/支出 | 运营收支和其他收入的手工记录 |

**筛选功能**：按月份、来源模块、收入/支出类型筛选 → 列表和顶部三张汇总卡片同步更新。

**导出**：按当前筛选条件导出 Excel。

## 6. 供应商管理

### 6.1 供应商管理

管理耗材供应商和物流供应商。

**类别管理**：系统预设"耗材商"和"物流商"两个类别，列表顶部用标签切换显示。

**新建供应商**：点击"新建供应商" → 选择类别 → 填写供应商名称、联系人、联系方式、地址 → 保存。

**操作按钮按类别区分**：

- 耗材商：显示"产品"和"详情"按钮
- 物流商：显示"物流"和"详情"按钮

**耗材产品录入**：点击耗材商的产品按钮 → 录入产品名、产品规格、规格报价、单价。

**物流报价录入**：点击物流商的物流按钮 → 按运输方式（海运/陆运）、货物类型（普货/商检货/敏感货）、发货仓库（深圳仓/义乌仓/广州仓）三个维度录入单价和时效。

**批量导入**：支持下载 Excel 模板，填写数据后上传批量导入。

**比价功能**：在供应商页面点击"比价" → 选择产品规格（耗材）或运输条件（物流）→ 查看所有供应商报价，按价格从低到高排序。支持 AI 分析。

**删除供应商**：点击操作列的红色删除按钮，确认后删除。

---

### 6.2 应付账款

管理对供应商的应付账单，支持新建、编辑、付款、导出。

**页面结构**：

| 区域 | 内容 |
|------|------|
| 总览看板 | 四张卡片：本月应付总额、逾期未付金额、已付金额、未付金额 |
| 供应商汇总 | 每个供应商的应付/已付数据，点击跳转该供应商账单 |
| 账单列表 | 支持筛选（供应商、日期范围、状态）、勾选、导出 |

**新建账单**：点击"新建账单" → 选择供应商 → 填写账单编号、日期、到期日、金额 → 可选填写费用明细、确认金额 → 上传账单附件 → 保存。

**付款**：点击账单行的"付款"按钮 → 弹窗显示应付总额、已付金额、本次付款金额、付款后余额（自动计算） → 填写金额和付款方式 → 上传付款凭证 → 确认。

**金额校验**：付款金额不能为负数，不能超过剩余应付金额。

**编辑**：可修改确认金额，当确认金额与原始金额不一致时标记差异。

**导出**：支持筛选后导出待付账单或供应商对账单。

**状态说明**：

| 状态 | 说明 |
|------|------|
| 待付 | 尚未付款 |
| 已付 | 全额付清 |
| 部分付款 | 已付部分金额 |
| 逾期 | 超过到期日未付清 |

---

### 6.3 付款计划

制定未来付款计划，执行后自动标记账单为已付。

**功能亮点**：

| 功能 | 说明 |
|------|------|
| 时间轴 | 未来四周每周的到期账单总额预览 |
| 模板 | 新建计划时可存为模板，下次新建时从模板下拉选择 |
| 执行 | 执行计划后，关联的所有账单自动标记为已付款 |
| 详情 | 点击计划行，弹窗显示包含的账单明细和总金额 |
| 导出 | 导出计划表 Excel |

## 7. 拼单管理

### 7.1 商品展示区

市场页面，展示系统内所有商品，供各仓库浏览参考。

### 7.2 拼单管理

跨仓库拼单采购，降低采购成本。

**核心流程**：

| 步骤 | 操作人 | 操作 |
|------|--------|------|
| 发起 | 仓库管理员 | 点击"发起拼单" → 填写物品名称、规格、目标数量、目标单价、截止时间 → 提交 |
| 参与 | 各仓库管理员 | 在拼单卡片上点击"参与拼单" → 填写参与数量和收货地址 → 勾选规则确认 → 提交 |
| 截止 | 超级管理员 | 点击"截止" → 系统汇总总数量、总金额，显示是否达到起订量 |
| 完成 | 超级管理员 | 点击"完成采购" → 录入最终成交单价、供应商、物流费 → 确认 |
| 取消 | 超级管理员 | 点击取消按钮 → 填写取消原因 → 通知参与方 |

**数据隔离**：所有开放中的拼单对所有仓库可见，参与后才记录仓库信息。

**历史记录**：展示已完成/已取消的拼单，可展开查看参与仓库明细、总成交金额、物流分摊、节省金额。

**节省计算**：节省金额 =（目标单价 - 成交单价） × 总采购量。

## 9. 常见问题

**Q：为什么充值申报保存后在对账中心看不到？**

A：对账中心只显示已上传截图的申报。请确认申报已上传付款截图，或在列表中点击"补传"按钮补充截图。

**Q：付款计划执行后应付账款的状态没变？**

A：执行付款计划后，关联的账单会自动标记为已付款。如果状态没变，请检查计划是否正确关联了账单。确认后刷新应付账款页面即可。

**Q：备用金余额不足怎么办？**

A：点击员工的"刷新"按钮补充金额。补充后余额增加，但不能超过系统设置的上限。

**Q：已还清的客户为什么还显示逾期？**

A：当欠款金额 ≤ 0 时，逾期天数自动归零。如果仍显示异常，请尝试为该客户新增一条还款记录触发重新计算。

**Q：报表导出下载不了？**

A：系统使用 fetch + token 方式下载，请确认登录状态有效，或尝试刷新页面后重试。

**Q：手机端怎么打开侧边栏？**

A：手机端侧边栏默认隐藏，点击左上角的汉堡菜单图标即可滑出。点击遮罩区域或 X 按钮关闭。

**Q：SSL 证书过期怎么办？**

A：服务器已配置 Let's Encrypt 自动续期，无需手动操作。
