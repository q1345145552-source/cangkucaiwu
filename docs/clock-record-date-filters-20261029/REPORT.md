## 修改

- GET `/api/v1/clock-in/records`：支持 `date` 或 `start_date/end_date` 或兼容 `month`；三种日期模式互斥，冲突400，非法日期422。均未传时按 `thai_today()` 返回泰国今天。
- `warehouse_id` 必须是当前账号获授权的有效仓库；显式仓库头与查询冲突拒绝。员工自助仍限定本人、本仓。`employee_id/employee` 是员工ID，`user_id/user` 是登录账号ID；原有正式绑定和兜底映射沿用。
- `page` 默认1，`page_size` 默认50、最多100。返回 `total/page/page_size`，按日期、时段、记录ID稳定排序。日期和其他筛选先于计数和分页。
- 两个打卡表格按员工分组分页，每页5人，只加载这5人指定期间的记录，每个请求最多100条。完整加载该组后才显示出勤格子，避免截断记录误显示缺勤。保留既有格子、统计、补卡按钮和导出。
- 考勤详情改用单日+员工ID；补卡标记只请求所选期间的补卡记录，按100条分批加载，查询切换后停止后续加载。
- 同轮修复备用金待审核、未对账列表、应付批量导出的结束日边界，以及操作日志日期参数的 PostgreSQL 类型错误。详见 DATE-INTERFACES.md。
