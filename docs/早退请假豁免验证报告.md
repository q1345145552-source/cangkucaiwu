# 已批准请假覆盖的时间不罚早退

本轮只改变工资早退判定前的一道豁免判断。没有部署，没有连接生产库，没有重算任何线上工资，没有改请假记录或前端。

## 判定

继续使用原工资准备阶段的“当天已通过请假”汇总。待审批、已驳回记录不会参与。

- 全天假（包括原本按全天处理的空小时数）不记早退。
- 下午半天假，且下班卡落在配置的下午时段，不记早退。
- 上午半天假不覆盖下午早退。
- 小时假：已批准小时合计 + 0.5 小时 >= 配置下班点对应的早退时长，则不记早退；不足则沿用原红线和模板扣款。
- 没有已批准请假，原样判断早退。

下班时间、下午开始时间读取配置中心。原时段4下班卡、红线、倍率、罚款计算方式均保留，迟到路径没有改动。新辅助判断在 `app/services/early_departure_leave.py`，工资文件只增加导入和早退前置条件。

## 精确案例：隔离环境手动重算

复现姓名 Khin Than Dar Tway，2026-10-04，四次卡 08:41:54、12:02:00、12:48:04、15:25:47。已批准小时假2.3，配置18:00下班。

早退2小时34分13秒，2.3+0.5=2.8小时足以覆盖，因此不罚。

| --- | --- | --- |
| 工时 | 5.96 | 5.96 |
| 上班工资 | 298 | 298 |
| 早退扣款 | 50 | 0 |
| 实发 | 248 | 298 |

测试模板日薪400、折算时薪50，5.96×50=298。这里是隔离样例金额，不是对线上该员工真实时薪的确认。

旧规则单先用同一工资计算器、原早退条件建立；恢复新条件后，先读取考勤/工资，确认旧单全部列不变，再显式调用 POST /payroll/{id}/recalc。新单的工时和全部逐日出勤明细与旧单完全一致，只有早退相关项目改变。请假表全部字段快照一致。
