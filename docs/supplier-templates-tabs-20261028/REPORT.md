## 第四步：顶部完整名称与顺序

改动前共16个按钮，顺序为：耗材商、物流、采购风险看板、采购价差月报、耗材模板、物流模板、多供应商耗材导入、多供应商物流导入、比价、采购汇总、价格监控、采购审批、收货验收、收货差异、采购单列表、新建供应商。按原权限有差异。

改动后管理员完整27个入口，顺序为：

1. **档案**：供应商档案 → 耗材商 → 物流 → 新建供应商。
2. **报价**：产品报价 → 物流报价 → 阶梯与有效期 → 耗材模板 → 物流模板 → 多供应商耗材导入 → 多供应商物流导入。
3. **采购**：采购单列表 → 采购审批 → 收货验收 → 收货差异。
4. **结算**：应付账单 → 付款计划 → 对账单。
5. **库存**：标准SKU目录 → 耗材库存 → 盘点。
6. **分析**：比价 → 供应商采购分析 → 采购汇总 → 价格监控 → 采购价差月报 → 采购风险看板。

保持原功能的实际名称：单笔付款仍在应付账单中，付款计划进入现有页面；对账单复用原下载接口；盘点进入现有库存页，仍需按原流程选择库存账户；产品和物流报价先明确选供应商，阶梯与有效期沿用产品内的阶梯报价入口。没有另造审批、盘点、付款或比价流程。

原16个按钮全部保留，原行内产品/物流、导入、阶梯报价、下单、映射等入口也保留。保留主支新加入的供应商状态、停启用和删除保护。原权限继续决定可见和可办理范围；不因为新导航授予权限。

六组之间有竖线和间距，组名在组内横滑时保持可见。手机为单行横向滚动、不换行，独立导航滚动区实测宽364px、内容宽2987px；每个按钮触摸目标至少44px。
