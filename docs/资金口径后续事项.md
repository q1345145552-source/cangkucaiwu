# 资金口径后续事项

用户在预支资金来源轮明确提醒并要求保留，2026-10-19：

1. 工资使用垫款发放，目前仍记“员工工资”成本。后续单独修正为垫款发放时不记成本，等公司归还垫款时再按用途计成本，避免重复记账。本轮绝不改工资发放的成本路径。
2. 实际核对当前仓库：归还垫款接口仍只记资金、不记运营支出。归还时按用途计成本尚未落到当前代码，须由后续专轮完成；不能误报为本轮已实现。预支用垫款本轮先按用户规则不计成本，不自动追补历史。
3. 报销使用垫款目前也记成本。以后归还路径改为计成本之前，应同时核对其口径，避免同一笔垫款在使用和归还时重复计入；本轮不改报销付款动作。
4. 本轮三种预支来源：公司账户通过时记员工预支支出、扣余额并入流水；垫款通过时仅占用可用额度；备用金通过时仅记开销台账，不再记成本或公司流水。待审批先不动资金，老板通过时统一执行；待审批仍占工资预支上限。
5. 旧预支来源字段不回填，不猜原账户，不补扣旧资金，不补记历史成本；已经生成的工资单不自动重算。
